# :fontawesome-solid-award: 50% | Milestones

Milestones provide student groups with the opportunity to build their final reproducible scientific paper incrementally. Each milestone represents 10% of the overall course grade (5 milestones × 10% = 50%).

There will be dedicated time during class meetings in the hands-on lab to work on these milestones and receive immediate instructor feedback, with final submissions completed after class.

!!! warning
    **Milestones are ALWAYS due before the beginning of class (08:00) on their scheduled deadline date, unless specified otherwise.**

## Milestone Workflow

Each milestone instructions page provides explicit guidelines, word limits, and starter templates.

1. Open the milestone by clicking the milestone link on the [Schedule](../schedule.md) page.
2. Read the instructions carefully, and work collaboratively in your group on your Typst manuscript and Jupyter notebook.
3. Export your files according to the naming convention (e.g. `da-milestoneX-groupY.pdf`, `.typ`, `.ipynb`) and submit them on the class WhatsApp group before the deadline.

## Grading Scale

Milestones will be evaluated on a 4-category rubric:

| Icon | Description |
| :-: | - |
| **✓+** | Exceptional, rigorous analysis and prose above and beyond expectations |
| **✓** | Complete, sound methodology and well-argued execution |
| **✓-** | Acceptable effort, but major analytical or formatting deficiencies |
| **∅** | Incomplete, unscientific, or missed submission |
