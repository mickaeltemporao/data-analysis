## Python
- [Python Official Website](https://www.python.org/): The official Python homepage and software downloads.
- [Python Official Documentation](https://docs.python.org/3/): Comprehensive language reference and standard library tutorial.
- [Python Tutorial (Kaggle)](https://www.kaggle.com/learn/python): Interactive introduction to Python basics.
- [Python Notes (Chris Albon)](https://chrisalbon.com/): Practical cheat sheets and reference notes for Python data science.
- [A Python Textbook in French](https://python.sdv.univ-paris-diderot.fr/01_introduction/#19-autres-ressources): Introduction to programming with Python (Université Paris Cité).

## Data Management (pandas)
- [pandas Official Website](https://pandas.pydata.org/): The official homepage of the pandas library for data analysis and manipulation.
- [pandas Official Documentation](https://pandas.pydata.org/docs/): Comprehensive user guide, API reference, and development guides.
- [pandas Getting Started Tutorials](https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html): Short introductory tutorials on key DataFrame workflows.
- [pandas Cheatsheet (PDF)](https://pandas.pydata.org/Pandas_Cheat_Sheet.pdf): Quick reference summary of essential pandas operations.

## Data Visualization (Altair)
- [Altair Official Website & Documentation](https://altair-viz.github.io/): Declarative statistical visualization library for Python based on Vega-Lite.
- [Altair Example Gallery](https://altair-viz.github.io/gallery/index.html): Visual catalog of charts, heatmaps, faceted plots, and distributions.
- [Altair Interactive Charts Guide](https://altair-viz.github.io/user_guide/interactions.html): Guide to tooltips, selections, and interactive brushing.

## Statistical Modeling (statsmodels)
- [statsmodels Official Website](https://www.statsmodels.org/): Official website for statistical modeling and empirical analysis in Python.
- [statsmodels Official Documentation](https://www.statsmodels.org/stable/): Comprehensive user guide, API reference, and release documentation.
- [statsmodels Formula API Guide](https://www.statsmodels.org/stable/example_formulas.html): Fitting OLS regressions using R-style formulas (`DV ~ IV + CV`).

## Development Environment (Visual Studio Code)
- [Visual Studio Code Official Website](https://code.visualstudio.com/): Official homepage and download for the VS Code editor.
- [VS Code Python Documentation](https://code.visualstudio.com/docs/languages/python): Official guide to configuring and running Python in VS Code.
- [VS Code Python Code Execution](https://code.visualstudio.com/docs/python/run-python-code): Guide to Smart Send, interactive scripts, and REPL execution in the integrated terminal.
